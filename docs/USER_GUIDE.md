# Руководство пользователя

## Вход и аккаунт

- При первом открытии — экран входа. Можно **зарегистрировать новый аккаунт** или войти.
- Демо-аккаунт: логин `demo`, пароль `demo123` (в нём лежат перенесённые примеры заметок).
- Данные каждого аккаунта полностью изолированы.
- Сменить аккаунт: нажать **«Выйти»** в правом верхнем углу (рядом с логином).

## Неделя и карточки

- В центре — неделя из 7 колонок. Стрелки ‹ › листают недели, «Сегодня» возвращает к текущей.
- Клик по названию недели открывает календарь.
- Новая заметка: кнопка **«+ Новая задача»** в колонке или клик по дню.
- Заметка редактируется по клику. Чекбоксы внутри текста автоматически считаются:
  когда все отмечены, карточка считается выполненной.
- Отмеченные карточки падают вниз в зону «Выполненные».
- Карточку можно **перетаскивать** мышью между днями, менять её порядок.

## Контекстное меню карточки (правый клик)

- **Заливка** карточки цветом, **штриховка**, **рукописный шрифт**, сброс стиля.
- **Теги** — назначить существующие или добавить новый.
- **Папка** — положить карточку в папку или убрать («Без папки»).

## Теги и фильтр

- Панель «Фильтр» — клик по тегу оставляет только заметки с этим тегом (можно несколько).
- Кнопка **«＋ Тег»** — создать, переименовать, удалить теги.

## Папки

- Панель «Папки» — переключение **«Все» / конкретная папка**. Фильтрация действует
  на неделю и на зону выполненных.
- Кнопка **«＋ Папка»** — создать (максимум **10 папок**), переименовать, удалить.
- Удаление папки **не удаляет заметки** — они просто выходят из папки.

## Стрелки между заметками

- На карточке слева/справа есть маленькие ручки «Соединить стрелкой»: зажмите и перетащите на другую карточку.
- Тип, цвет, ширина, пунктир стрелки настраиваются в её контекстном меню.

## Цвет колонки

- Кнопка-«капля» в шапке колонки дня задаёт цвет всего дня; повторный клик — сброс.

## Клавиатура

| клавиши | действие |
|---|---|
| ← → | навигация по дням недели |
| ↑ ↓ | переход между заметками дня |
| Enter | открыть редактор (или новую заметку) |
| Esc | выйти из навигации / снять выделение |
| Shift + клик | множественное выделение карточек |
| Shift + колёсико | горизонтальная прокрутка недели |
